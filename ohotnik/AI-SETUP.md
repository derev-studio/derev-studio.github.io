# Подключение настоящего ИИ-поиска к «Охотнику»

Сайт: https://derev-studio.github.io/ohotnik/

Это отдельный Cloudflare Worker. Действующий Worker фотогалереи photo-ai-qwen НЕ трогать.

## Разовое подключение

1. Открой https://dash.cloudflare.com/ → Workers & Pages → Create Worker. Назови его **ohotnik-ai**. Для прежнего аккаунта ожидается адрес `ohotnik-ai.qerevv.workers.dev`.
2. Открой файл `ohotnik/ai-search-worker.js` из репозитория и вставь его код в редактор нового Worker. Нажми Deploy.
3. Worker → Settings → Bindings → Add → Workers AI. Имя привязки (binding): **AI**.
4. Зарегистрируй бесплатный аккаунт https://app.tavily.com/ . На 18 ноября 2026 года план Researcher даёт **1000 API-кредитов в месяц без карты**. Скопируй API-ключ на своей стороне.
5. Worker → Settings → Variables and Secrets → Add → тип Secret → имя **TAVILY_API_KEY** → вставь ключ. НЕ размещай ключ в GitHub, HTML или чате.
6. Опубликуй настройки. Проверь `https://ohotnik-ai.qerevv.workers.dev/search?q=фильтр%20для%20воды`.
7. В «Охотнике» ничего дополнительно редактировать не нужно: он уже умеет обращаться к этому Worker и показывает найденные страницы магазинов внутри своего интерфейса. До настройки работает нынешний поиск.

## Принцип

- Cloudflare Workers AI переводит русский запрос в точный торговый иврит, сохраняя бренд и модель.
- Tavily ищет по опубликованным страницам KSP, ARKA, Ivory, Home Center, ACE, Kravitz, Zap и других магазинов.
- В интерфейсе показываются настоящие заголовки страниц, магазин, описание и ссылка на продавца. Сервис не выдумывает фото, цену или наличие.
- При недоступности сервера остаются рабочий локальный каталог и магазинные ссылки.

## Важные ограничения

- Не каждая найденная страница является карточкой конкретного товара: могут встречаться и тематические разделы.
- Свежие цены и наличие в филиалах пока не загружаются автоматически. Для этого нужен отдельный официально разрешённый источник.
- Чтобы не тратить лимит впустую, Worker кэширует одинаковые запросы; для публичного массового использования желательно добавить Cloudflare rate limiting.
